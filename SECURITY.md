# Security

Ghost Cloak is experimental and has NOT undergone an independent security audit. It must not yet be relied upon for high-risk communications.

No server decryption keys, recovery escrow, plaintext telemetry or administrator message access is permitted. Report vulnerabilities privately to the repository owner through an available private channel; never post keys, tokens or private conversations in public issues. No formal disclosure inbox is configured yet.

See [the current audit](SECURITY_AUDIT_CURRENT.md), [security architecture](protocol/SECURITY.md), and [the threat model](protocol/THREAT_MODEL.md). The Phase 1 security reviews record historical implementation stages. A current deployment runbook exists, but this document does not attest to a live deployment or independent audit.
